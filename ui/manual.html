    安裝：雙擊一次，精靈帶你走完

    生圖站在你自己的電腦上畫圖，不用連到別人的伺服器，畫什麼都只有你看得到。畫圖的引擎是 ComfyUI，安裝精靈會幫你準備好；電腦裡已經有 ComfyUI 的話，也可以直接沿用。

    項目需要說明
    系統Windows 10／11（64 位元）—
    顯示卡NVIDIA，顯存 8GB 以上，驅動 580 版以上開發時用 RTX 3070 8GB 實測；顯存越大越快。驅動太舊精靈會提醒，要自己到 NVIDIA 官網更新
    A 卡（AMD）實驗性支援：RX 5000 以後的獨顯（RX 5000／6000／7000／9000）、680M／780M／860M／890M／8060S 這類內顯；要最新的 AMD Adrenalin 驅動作者手上沒有 A 卡，還沒在 A 卡上實際畫過圖。RX 7000、RX 9000 和 Ryzen AI 300／Max 內顯直接用官方 AMD 版；其他的裝完會再換一套支援那張卡的 PyTorch（多下載約 1～1.4GB）。Vega、RX 500 以前的卡沒有能用的 PyTorch
    Intel 顯示卡實驗性支援：Arc 獨顯（A／B 系列）、Core Ultra 的 Arc 內顯還沒實際測過。UHD、Iris Xe 內顯不支援
    沒有能用的顯示卡照樣能裝：圖庫、提示詞庫、雲端顯卡都能用ComfyUI 會用 CPU 跑（畫一張要好幾分鐘）；生圖助手可以接「雲端顯卡」
    記憶體16GB 起跳，建議 32GB做影片時最吃記憶體
    硬碟基本版約 50GB；完整版約 80GB模型很大，建議放 SSD

    步驟

    • 雙擊 繪匣 PaintDeck_26.1031.4_x64-setup.exe。安裝檔沒有付費簽章，Windows 可能跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
    • 從 Anima／PaintDeck 舊版接手：精靈會優先選原設定的資料與 ComfyUI。找到多份圖庫時請自行選擇，不會自動挑圖片最多的。資料資料夾不用改名，也不用搬模型。找不到原位置時，可按「自己指定舊資料」；選到內層 data 會自動辨識外層，原路徑失效或資料庫讀不到時不會新建空白圖庫取代它。
    • 開始前確認「本次使用的位置」。沿用資料時，模型頁預設不新增勾選下載，缺哪些功能再自行勾選。第一頁可展開「程式位置與舊版安裝紀錄」核對路徑；不要同時開新舊版，同資料夾的舊解除安裝項目先確認再處理，MCP 設定需重新複製。
    • 第一次打開會進安裝精靈，一共四步：檢查電腦 → 資料與 ComfyUI 放哪裡 → 要下載哪些模型 → 安裝。右上角可以切換繁體中文／简体中文／English。
    • 檢查電腦會看顯示卡、驅動版本、硬碟空間，還有 Windows 有沒有 Visual C++ 執行階段。缺 Visual C++ 的話，安裝時精靈會從微軟官網下載（約 18MB）幫你裝，會跳出一次系統確認視窗，按「是」就好。
    • 不是 NVIDIA 顯示卡？精靈會自己看是哪一家、哪一代，第一頁就講清楚會怎麼裝。A 卡和 Intel 都是實驗性支援，作者手上沒有這些卡，還沒在上面實際畫過圖；開不起來時，狀態列「顯存」那格會寫 ComfyUI 關掉的原因，麻煩截圖回報。
      • A 卡（AMD）：「自動下載 ComfyUI」會改裝官方的 AMD 版免安裝包（約 1.5GB），AI 改寫改裝 llama.cpp 的 Vulkan 版（約 30MB）。RX 7000、RX 9000、Ryzen AI 300／Max 內顯直接能用；RX 5000、RX 6000、680M、780M、860M 這些官方 AMD 版沒附的，裝完會再從 AMD 官方的套件庫把 PyTorch 換成支援那張卡的 ROCm 10 版（多下載約 1～1.4GB）。Vega、RX 500 以前的卡太舊，沒有能用的 PyTorch。
      • Intel 顯示卡：Arc 獨顯、Core Ultra 的 Arc 內顯會改裝官方的 Intel 版免安裝包（約 1.3GB）；UHD、Iris Xe 內顯不支援。
      • 沒有能用的顯示卡：照樣能裝，ComfyUI 會用 CPU 跑（很慢，只適合試試看），生圖模型預設不勾，生圖助手可以改用「雲端顯卡」。
      • 比較舊的 N 卡（GTX 10 系列以前）：新版 PyTorch 不支援這些卡，精靈會自動改下載官方給舊卡的版本（CUDA 12.6，約 1.9GB），驅動版本的門檻也比較低。舊卡顯存多半不大，畫 Qwen、MOSS 會很慢或不夠。
      • 精靈認錯、或偵測不到（例如精簡版 Windows）：第二頁「ComfyUI 版本」可以自己選 NVIDIA／NVIDIA 舊卡／AMD／Intel／用 CPU 跑／用我自己已經能跑的 ComfyUI；選 AMD 時旁邊還能選「A 卡架構」（照型號挑）。選過的會記住，之後的「安裝與修復」都照它。
      • 已經在用 A 卡的 ComfyUI：秋葉 A 卡整合包這類 ZLUDA 版、DirectML 版精靈都認得，選它就好，不會被標成用不了；生圖站會照它的方式開（ZLUDA 版用它的 zluda.exe，DirectML 版自動加 --directml）。
      • AMD、Intel 版 ComfyUI 官方只寫 Windows 11，Windows 10 沒驗證過，精靈會提醒但不會擋。
    • 電腦裡已經有 ComfyUI？精靈認得官方免安裝版、秋葉整合包、StabilityMatrix、Pinokio、SwarmUI、官方桌面版和自己 git clone 的（venv）。掃描沒找到的話，選「自己指定 ComfyUI 資料夾」，按「選資料夾…」挑整包的最外層就好。ComfyUI 的 Python 放在別的地方（conda 環境、ComfyUI 外面的 venv）的話，在底下填那個 python.exe 的位置；平常用它自己的啟動器開的（例如繪世啟動器），勾「我自己開這份 ComfyUI」，生圖站只連過去。沿用的 ComfyUI 比 0.38 舊時會標紅：有些內建功能會缺節點，建議改選自動下載或先更新。沿用的是官方免安裝版、又比 0.43.0 舊，按「開始安裝」會順便把它升級到 0.43.0（MOSS 照指令改圖、色彩深度控制要新版）；繪匣從舊版更新上來的，第一次開程式時也會自動升級（約 1～3 分鐘，先裝好新套件才換程式，沒網路就照舊用原本的版本）：模型、圖片、外掛都不動，換掉的舊檔備份在 ComfyUI 旁邊的 待刪除\ComfyUI升級備份_時間。
    • 模型分成好幾包，想要哪個功能就勾哪一包（每包的內容和大小見下面的表）。上面的快速鈕可以一次選好：只裝動漫（Anima）＝只有 Anima 那一包，約 11GB；基本版＝Anima 動漫、Qwen 2.1 編輯、MOSS-Image 文生圖繪圖三種模型的全部生圖功能，約 42GB；完整版＝全部勾，約 67GB；全不選＝只裝引擎，模型之後再回來補勾。勾了要靠別包的（例如「Qwen 2.1 姿勢參考」要先有 Qwen 2.1），那一包會自動跟著勾；已經裝好的包會打勾鎖住。顯存 8GB 以下或記憶體 16GB 以下的電腦，精靈會先幫你選「只裝動漫」（Qwen、MOSS 的模型很大，這種電腦跑起來很吃力），想要別的自己再勾。
    • 兩包常用 LoRA 有幾個檔放在 Civitai，要登入才能下載（基本版不用）。沒填 Civitai API key 的那幾個會顯示「要登入」，其他照常下載。之後到「設定」填好 key（申請方法見下一段），再回精靈按一次就會補齊。
    • 在中國大陸：Hugging Face、GitHub、Civitai 要開梯子才連得到。梯子開「系統代理」「PAC」或「TUN（虛擬網卡）」模式都可以，生圖站會自動跟著用；精靈第一頁會先測一次連線，告訴你哪幾個網站連不到。Hugging Face 連不到時會自動改從鏡像 hf-mirror.com 下載。梯子關了但系統代理忘了關，生圖站會自動改成直連。要手動填代理，到「設定」→「網路」。
    • 安裝時最上面有總進度、速度和大約還要多久；安裝期間電腦不會自己睡著（螢幕會照常關）。
    • 下載中途斷網沒關係：有項目沒裝好或按了「停止下載」，標題會寫「安裝還沒完成」，按「重試」會接著裝，已經下載的不會重抓。只有幾項沒裝好、其他都能用時，也可以先按「先開始使用」。GitHub 上的檔連不到時，訊息會寫網址和要放的資料夾，可以用別的方法下載好放進去再按「重試」。
    • 電腦裡已經有模型？進到「要下載哪些模型」那一步會自動掃描：它會看過每顆硬碟，找出別的 ComfyUI、A1111／Forge 裡的模型（用捷徑、junction 連到別顆硬碟的也找得到）。勾選的資料夾原地使用，不搬動、不複製，下面的「還缺幾個」會扣掉找到的，就不用再下載一份。

    從 Anima 生圖站升級

    1. 從系統匣右鍵「結束」，關掉舊版。
    2. 到 Windows 設定解除安裝「Anima 生圖站」，不要勾「刪除應用程式資料」。
    3. 安裝「繪匣 PaintDeck」。自己瀏覽選資料夾時，安裝程式會再加一層 繪匣 PaintDeck。
    4. 第一次開啟會沿用設定與圖庫。有用 MCP 的，到「設定 → 給 AI 操作」重新複製設定。

    改名後新舊版會各有一筆解除安裝紀錄與捷徑，兩套共用設定與連接埠，不能同時開。若裝在同一個資料夾，解除安裝舊版可能連新版一起移除。勾刪除應用程式資料會清掉程式記住的資料位置，需要重跑精靈指回去；圖庫檔案仍在原資料資料夾。

    26.10.24 與更早版本沒有 App 內更新功能，第一次仍須手動安裝支援更新的新版本。公開版的「設定 → 程式更新」可開關背景檢查、查看新版說明；按「下載並更新」並確認後才下載、驗證簽章、安裝並重新開啟。生圖、影片、改寫或下載模型未完成時不能更新。連不上 GitHub 會安靜略過，也能稍後手動再查。私人版維持手動更新，請使用私人安裝檔。這項功能尚未打包發布。

    申請 Civitai API key（免費，五分鐘）

    Civitai 是最大的模型、LoRA 分享站。很多檔案要登入才能下載，生圖站用「API key」代替你登入。安裝精靈裝常用 LoRA，還有「下載」頁抓 LoRA 都會用到。

    1. 打開 civitai.com，右上角 Sign In 註冊或登入（Google、Discord 帳號都可以）。
    2. 點右上角自己的頭像 → 選單裡的齒輪 Settings（帳號設定頁，網址是 civitai.com/user/account）。
    3. 往下捲到 API Keys 那一塊，按 + Add API key，名字隨便取（例如 anima），按 Save。
    4. 畫面會出現一長串金鑰，只會顯示這一次：按旁邊的複製鈕。不小心關掉了就刪掉重建一組。
    5. 回到生圖站：左邊「設定」→ 最上面的 Civitai API key 欄位貼上 → 按 儲存，下面會顯示已設定。

    金鑰只存在你這台電腦：用 Windows 的加密存起來，匯出設定檔、恢復原廠都不會帶走它。別把金鑰貼給別人或貼到網路上；外洩了就到同一頁刪掉重建。

      03

      提示詞：看你用哪個模型

      生圖站有三家模型，寫法不一樣。控制台下面的「模型」選單換模型，步數、CFG 會自動換成那個模型的預設值。

      模型擅長提示詞
      Anima動漫、插畫，速度最快英文 tag，逗號隔開
      Qwen 2.1寫實照片、改圖、多圖參考完整的英文句子
      MOSS-Image寫實、排版、在圖上寫字完整的英文句子，字放在引號裡

      Anima 的寫法

      • 開頭放品質和評級：masterpiece, best quality, score_7, safe,。評級一定要寫，可選 safe、sensitive、nsfw、explicit。
      • 畫師名字前面加 @，例如 @kyomu，不加幾乎沒效果。
      • 不知道英文 tag，就直接在框裡打中文，例如「貓耳」，下面會列出對應的 tag。
      • 游標停在某個 tag 上按 Ctrl↑，每按一次權重加 0.05。
      • {red|blue} 會讓每張圖隨機挑一個。

      Qwen 2.1、MOSS-Image 的寫法

      • 像在描述一張已經拍好的照片：先講媒材和主體，人物寫明是成年人並給年紀（例如 a woman in her mid twenties），再講背景、姿勢、衣服、光線。
      • 五官、皮膚、頭髮一樣一樣寫清楚，臉會更漂亮也更穩。
      • 要畫在圖上的字直接寫進句子、用引號框起來，例如 a shop sign that reads 「小克的咖啡店」。MOSS 寫字最準，繁中、英文都行。
      • 這兩家都不吃權重，(tag:1.2) 會被當成文字，框裡會畫紅色波浪線提醒你。想強調什麼，就多用一句話描述它。
      • Noct Q Anime（Qwen 的動漫版）開頭要寫 An anime illustration of…，沒寫會畫成照片。
        04

        AI 改寫：一句中文變成完整提示詞

        不想自己寫英文，就打開提示詞框下面的「AI 改寫提示詞」。用一句話說你想要什麼，改寫模型會寫成一段完整的英文提示詞。不滿意可以一直微調，每一版都會留著，最多 30 版。

          改寫預設

          • 「改寫預設」選單決定交給 AI 哪一份工作說明。選「自動」時，括號裡會寫出現在用的是哪一份，例如「自動（現在＝Anima 版）」。
          • 可以手動選文生圖版（Qwen 2.1／MOSS）、改圖版（Qwen 2.1，會看參考圖）、Anima 版或成人（體位）。選的跟模型對不上時會跳出 ⚠ 提示。
          • 成人（體位）三種模型都能用：Qwen 2.1、MOSS-Image 寫成英文句子，Anima 寫成 tag 加句子。姿勢從 110 種的「姿勢大彙整」挑，選單裡標 ◆ 的有 3D 人偶參考圖。
          • 勾「姿勢參考圖」會照 3D 人偶擺姿勢，身體貼合更準：Qwen 2.1 用 ControlNet，MOSS-Image 從人偶的深度圖重畫。Anima 不能用。
          • 要改工作說明的內容，按旁邊的「自訂改寫規則」，會跳到設定頁對應的那一份。
          • 「用哪顆模型」可以直接切 35B（較聰明、吃記憶體）、9B（較快、省記憶體）或自動（有 35B 就用 35B）。跟設定頁的「通用模型」是同一個設定，生圖助手、導演台分段也會跟著換。

          三個勾選

          • 中文對照：多寫一段中文，讓你看得懂它寫了什麼。
          • 深度思考：先想再寫，比較慢，可以看思考過程。
          • 生成時自動改寫：按生成前先改寫一次。同樣的想法會直接用上次的結果。

          顯卡只有 8GB 也能用：改寫前會先請 ComfyUI 卸載模型，按生成前會先關掉改寫模型，兩邊輪流用顯存。在想法框裡按 CtrlEnter 是「改寫」，不是生成。

          05

          版面框：指定誰、什麼東西放在畫面哪裡

          提示詞只能說「畫面裡有什麼」，很難說「放在哪裡」。版面框讓你在一塊畫布上拉框：這個框是角色、那個框是一樣東西、下面那個框寫一行字，MOSS-Image 就會照框的位置畫。不畫框也沒關係，就是一般的 MOSS 生圖。

          步驟

          1. 「模型」選 MOSS-Image，模式選「文生圖」或「圖生圖」。提示詞框下面會多一格 版面框；換成 Anima、Qwen 2.1 或其他模式時，這一格會藏起來（框還留著，換回來就出現）。
          2. 先在提示詞框寫整張圖：場景、氣氛、光線、畫風。框裡只寫那一樣東西本身。
          3. 點開「版面框」，會看到一塊小預覽。點預覽（或按「打開畫框視窗」）會跳出一個大視窗：左邊是放到最大的畫布，右邊是每個框的設定。畫布的形狀跟你設的寬高一樣，右下角會顯示尺寸；圖生圖選自動尺寸時，形狀跟輸入圖一樣。
          4. 上面「新畫的框是」先選角色、物件或文字，在畫布上按住滑鼠拖一個框，放開。右邊多一行設定，游標會直接跳到描述欄（文字框跳到「要畫的字」）。
          5. 那一行最前面可以再改類型：角色、物件或文字，後面寫描述。角色寫「誰、長相、穿著、動作」，物件寫「什麼東西、長什麼樣子」，中文英文都可以。
          6. 選「文字」會多一格「要畫的字（照抄）」：把要出現在圖上的字一字不差打進去。描述欄改寫字的樣子（字型、顏色、大小），不寫也行。
          7. 要幾個就拉幾個，最多 16 個。都寫好了按右上角 完成（或 Esc、點視窗外面）回到生成頁，小預覽和底下的清單會照你畫的顯示；點清單的某一行，會打開大視窗並選好那個框。照平常按「生成」。

          調整框

          • 拖框左上角的標籤（例如「01 角色」）＝移動；拖右下角＝改大小；點一下＝選取。
          • 選取後按 Delete 刪掉，方向鍵一次挪一點，按住 Shift 一次挪多一點，Esc 取消選取。也可以按那一行最後面的 ✕ 刪掉。
          • 大框裡面可以再拉小框，例如整個人一個框、手上拿的杯子再一個框。小框會疊在上面，點得到。
          • 全部清除 一次刪光（會先問一次）。
          • 畫面上寫著「（還沒寫描述）」的框不會送出去。拉得太小的框會直接消失。

          框會跟著存

          • 重新整理、關掉再開，框都還在。「存成整套」會連框一起存進提示詞庫。
          • 圖庫按「重用參數」：有框的圖會把框帶回來並自動展開；沒框的圖會清掉現在的框。
          • AI 改寫只改提示詞，框不會動。開「高解析修復」也沒關係，框會跟著放大後的尺寸換算。

          導演台：每段的第一格也能拉框

          1. 在生成頁選好 MOSS-Image，到「導演」頁「第一格的畫法」按 用生成頁目前的設定。
          2. 每一段的卡片會多一格可以收合的 版面框。點開，點小預覽跳出大視窗，照上面的方法拉框、選類型、寫描述。畫布固定是橫的 16:9，跟第一格一樣。
          3. 按這一段的 重寫提示詞，AI 會照框的位置重寫這段第一格的畫面描述。之後畫第一格時，框也會一起交給 MOSS。
          • 勾了「接上一段」、或用「指定第一格…」挑好圖的段落，不會另外畫第一格，所以沒有版面框。
          • 框跟著專案存。導演台正在跑的時候不能改框。

          為什麼只有 MOSS：MOSS-Image 訓練時就學過「照框排版」，Anima、Qwen 2.1 沒學過，送過去也看不懂，所以選它們時版面框會藏起來。

          06

          七種模式，一排琴鍵切換

          控制台最上面那排鍵決定這次要做什麼。除了文生圖，其他都要先放一張圖：拖進框裡、按 CtrlV 貼上，或按「從圖庫選」。觀景窗和圖庫大圖下面也有同名的按鈕，按一下就把那張圖送過去（擴圖在「玩法…」裡面）。

            模式適合關鍵設定
            圖生圖照一張圖重畫重繪幅度：Anima 預設 0.6；MOSS 0.7 以下構圖不變、0.8 以上幾乎整張重畫
            局部重繪只改一小塊畫遮罩；範圍選「只重繪遮罩區」最適合修臉、修手
            擴圖把畫面往外延伸：橫圖變直圖、補出被裁掉的身體或背景四邊各往外擴幾像素，或按快捷鈕；步驟見第 07 章
            多圖參考人、衣服、場景各取一張重組只有 Qwen 2.1；第 1 張是底圖，提示詞用 <image1> 指名
            放大把圖放大變清楚倍率 1.5／2／3／4，可加 AI 精修
            四視圖角色設定稿一次改：換衣、改色每個視角同步改；要點名改哪件，例如「紅色西裝外套」

            附加功能

            • 高解析修復：先畫小圖，放大後再畫一次細節。倍率 1.5、重繪 0.4 最常用。
            • 構圖控制（只有 Anima）：照另一張圖的線條、塗鴉或深度擺構圖。控制圖留空，就用輸入圖。
            • 生成後自動修臉、X/Y 對照表、塗鴉畫布：也在「附加」這一區，用法見下一章。
            • 拿去 ComfyUI 改…（模型那一格下面）：把目前這個功能照目前的設定存成 ComfyUI 工作流，存的位置自己選，視窗裡有三步說明。想在 ComfyUI 裡自己改內建的流程時用，改好可以匯回來取代內建的（第 16 章）。還沒放輸入圖、遮罩也能存，會先用佔位圖代替。

            四視圖不用切模型：它會自動用 Qwen 2.1 官方 Turbo，所以要先裝好它（基本版就有）。

            07

            生圖玩法：擴圖、修臉、差分、去背、對照表

            畫好一張圖之後，還能拿它玩很多花樣。大部分在觀景窗或圖庫大圖下面的 玩法… 按鈕裡；X/Y 對照表、塗鴉畫布在生成頁的「附加」區；批次在提示詞框下面。做出來的圖都會進圖庫，原圖不會被蓋掉。

            玩法在哪裡要先有
            擴圖模式鍵「擴圖」，或「玩法…」→「擴圖」不用另外下載；三種模型都能用
            變體（4 張）「玩法…」不用另外下載
            修臉、修手「玩法…」；或「附加」勾「生成後自動修臉」偵測模型 SAM3.1（功能包「修臉／修手」）
            差分（表情／動作）「玩法…」Qwen 2.1 官方 Turbo（功能包「Qwen 2.1 編輯」）
            一鍵去背「玩法…」去背模型 BiRefNet（功能包「一鍵去背」）
            塗鴉畫布「附加」的「塗鴉畫布」、輸入圖旁的「畫草圖」不用另外下載
            X/Y 對照表「附加」的「X/Y 對照表」不用另外下載
            批次提示詞提示詞框下面的勾選框不用另外下載

            擴圖：把畫面往外延伸

            1. 兩種開法：控制台最上面那排鍵按 擴圖，再放一張圖（拖進框、CtrlV 或「從圖庫選」）；或在觀景窗、大圖按 玩法… → 擴圖，那張圖會直接送過來。
            2. 「擴圖」區有四格：往上、往下、往左、往右，各填要多補幾像素（照原圖的大小算）。
            3. 懶得算就按快捷鈕：四邊各 +25%、左右 +50%（變寬）、上下 +50%（變高）、往下補一半（補身體）、變成 16:9、變成 9:16、變成 1:1。清除 全部歸零。
            4. 看下面的預覽：斜線的地方就是要補出來的部分，「擴圖」標題旁邊會顯示擴完的尺寸。
            5. 提示詞寫整張圖要長什麼樣，連補出來的地方一起寫，例如補出來的腳、地板、天空。
            6. 按「生成」。
            • 新舊交界看得出接縫，就把「接縫柔化」調大一點。
            • Anima 接得最順。Qwen 2.1 會自動在提示詞前面加一句「把灰邊延伸成場景」，你不用自己寫。
            • 擴完的圖最大 4096×4096，超過會叫你改小。

            變體：同一張圖，再來 4 張差不多的

            • 「玩法…」→ 變體（4 張）。照原圖的模型、提示詞、LoRA，用圖生圖輕輕重畫一次，每張換一個種子。
            • 構圖幾乎一樣、細節各有不同，適合「這張很好，但想看看別的可能」。
            • 去背、對照表、影片、放大、四視圖、差分做出來的圖不能直接做變體，會請你先按「圖生圖」自己調。

            修臉、修手：自動找出來，放大重畫

            1. 觀景窗或大圖按 玩法…，選 修臉、修手 或 修臉＋修手。
            2. 生圖站先用 SAM3.1 找出每張臉（每隻手）。第一次要載入偵測模型，多等十幾秒。
            3. 右下角會跳出「找到幾處」，接著每一處裁下來、放大重畫、再貼回去，一次最多 8 處，大的先修。
            4. 修好的是一張新圖，圖庫裡的模式叫「修細節」，原圖留著可以對照。
            • 想每張都自動修：「附加」區勾 生成後自動修臉。之後文生圖、圖生圖每畫完一張，就會自動多排一張修好臉的。
            • 重畫的力道在「生成後自動修臉」那一格展開後的「修臉重繪幅度」，預設 0.4。調大改得多，但臉可能變成另一個人。
            • 說「找不到臉」：臉太小、太側面或被擋住時會找不到。改用「局部重繪」自己塗遮罩修。

            差分：同一個角色換表情、換動作

            1. 觀景窗或大圖按 玩法… → 差分（表情／動作），會跳出一個視窗，左邊是原圖。
            2. 點選要的表情：微笑、大笑、生氣、哭泣、害羞、驚訝、得意、無奈、眨眼、睡著；或動作：揮手、比讚、比 V、比愛心、雙手抱胸、托腮、回頭看、舉手。可以選很多個，點到的會亮起來，再點一下取消。
            3. 清單裡沒有的，寫在「自訂」框，一行一個，例如「把頭髮改成雙馬尾」「讓角色戴上眼鏡」，中文英文都可以。
            4. 最下面選每一項要畫幾張（每項 1／2／3 張），旁邊會算出「共幾張」，按右邊的 送出。
            • 用 Qwen 2.1 改圖：臉、髮型、衣服、畫風盡量跟原圖一樣，只改你選的那件事。做角色表情包、立繪差分很好用。
            • 生成頁選的是 Qwen 2.1 時，步數、CFG、LoRA 都照生成頁；選別的模型時，自動換成官方 Qwen 2.1 Turbo（8 步），不用自己切。

            一鍵去背

            • 觀景窗或大圖按 玩法… → 一鍵去背。去掉背景，存成透明背景的 PNG。
            • 圖庫和大圖用灰白棋盤格表示透明的地方。下載下來就是透明的，可以直接拿去做貼圖、頭像，或疊到別的圖上。

            塗鴉畫布：自己畫草圖，AI 幫你畫完

            1. 三個地方都能打開：「附加」區的 塗鴉畫布、圖生圖輸入圖旁的 畫草圖、構圖控制裡的 自己畫草圖。
            2. 畫布的形狀跟生成頁設的寬高一樣。上面選 筆 或 橡皮擦，挑顏色、拉「粗細」。畫錯按 復原（或 CtrlZ），清空 整張重來。
            3. 想照一張圖描：勾 墊輸入圖描，生成頁的輸入圖會淡淡墊在下面，不會畫進草圖。
            4. 畫好按其中一個：當構圖控制（只有 Anima）照你的線條構圖、AI 自己上色，黑線白底的線稿最準；當圖生圖底圖（每種模型都行）可以畫色塊，會自動切到圖生圖、重繪幅度設成 0.85。
            5. 回到生成頁寫好提示詞，按「生成」。

            X/Y 對照表：一次比較兩種設定

            1. 先在生成頁把模型、提示詞、LoRA、模式都設好。對照表會照這些設定畫，只改你選的那一兩樣。
            2. 「附加」區按 X/Y 對照表。
            3. X 軸選要比較什麼，後面填幾個值，用逗號隔開，例如 CFG 填 1, 3, 5。可以比：種子、步數、CFG、取樣器、排程、LoRA 強度、提示詞替換、重繪強度。選好會先幫你填一組常用的值。
            4. 想同時比第二樣，Y 軸也選一個；不用就留「（不用）」。下面會顯示「共幾格」，最多 36 格。
            5. 按 開始。每一格各畫一張，全部畫完會自動拼成一張大表存進圖庫（模式叫「對照表」），視窗裡也可以按 下載。
            • 種子沒選成軸的話，所有格子用同一個種子，比較才公平。
            • 比 LoRA 強度：先在生成頁掛好那個 LoRA，軸旁邊再選要比哪一個。
            • 提示詞替換：第一個值是提示詞裡要被換掉的字，後面每個值各畫一格，例如 red hair, blue hair, silver hair。第一格就是原本那句。
            • 重繪強度只有圖生圖、局部重繪能比。放大、四視圖不能做對照表。
            • 有幾格失敗也照樣拼，那一格會寫「失敗」。

            批次提示詞：一次排很多句

            1. 在提示詞框裡，一行寫一句提示詞。
            2. 勾提示詞框下面的 批次：每行一句提示詞，各畫一組。
            3. 按「生成」：每一行各畫「張數」那麼多張。例如 5 行、張數 4，就是 20 張，全部排進任務面板。
            • 一次最多 50 行。
            • 勾著批次時，「生成時自動改寫」不會跑（改寫會把整框換成一段）。
            • 用完記得取消勾選，不然下次寫好幾行的提示詞，會被拆成好幾句分開畫。

            修臉、去背、差分說找不到模型：修臉要 sam3.1_multiplex_fp16.safetensors（放 models\checkpoints），去背要 birefnet.safetensors（放 models\background_removal），差分要 Qwen 2.1 官方 Turbo。安裝精靈勾「修臉／修手」「一鍵去背」「Qwen 2.1 編輯」就會下載（基本版都有）；已經裝好的，到「設定」→「安裝與修復…」補勾再按一次安裝。

            08

            LoRA：幫模型換一套畫風

            LoRA 是小小的外掛檔，可以讓模型學會某種畫風、某個角色或某件衣服。在「下載」頁從 Civitai 找，下載完會自動出現在 LoRA 清單，觸發詞也一起存好。

              • 搜尋前先在左邊選基底模型：Anima、Qwen 2.1 或 MOSS Image。三家的 LoRA 不能混用，家族不對的會被劃掉，生成時會略過。
              • 預設強度 0.8。不確定要多少，按卡匣上的 ⇆，用同一個種子各畫一張不同強度來比。
              • 「LoRA」頁可以替每個 LoRA 寫標題、觸發詞、建議強度和備註，生圖助手也會讀這些說明。程式附的 LoRA（含 MOSS LoRA 合集每一顆）已經寫好用途、觸發詞和強度範圍，開站時自動補上；你改過的不會被蓋掉。
              • 有些模型要登入 Civitai 才能下載：到設定頁貼上 Civitai API key，只存在這台電腦（申請步驟見第 01 章）。
              • LoRA 已經放在別的地方（A1111 的 models\Lora、別的 ComfyUI）？到「設定 → 模型與工作流」把那個資料夾加進「外部模型資料夾」就能直接用。手上的單一檔案，拖進同一區的「加裝模型」框，生圖站看檔案內容自動放進對的資料夾。

              MOSS 想快一點：選 MOSS 模型時會出現「MOSS 快速」勾選框，勾了自動掛加速 LoRA 0.35、步數改 10，一張從約 40 秒變約 16 秒。要先下載加速 LoRA（檔名 moss_speed_dmd…）；它在安裝精靈的「MOSS-Image 文生圖繪圖」包裡；沒有的話勾了會問要不要直接下載（約 1.1 GB），下載好自動勾上。

              MOSS 照指令改圖：MOSS 模型＋「圖生圖」模式會出現「照指令改圖」勾選。勾了之後輸入圖當參考圖，提示詞寫要怎麼改（例如「把外套改成紅色，其他保持不變」），會自動掛上 MOSS 編輯 LoRA（moss_edit_chinoll，也在 MOSS 包裡，沒有的話勾了會問要不要下載；Civitai 的 MOSS 編輯 LoRA 也能用）。重繪固定 1、參考圖自動縮到約 0.5MP，8GB 顯卡 20 步實測約 1 分鐘。繪匣更新後開站會自動換上新的 MOSS 支援；ComfyUI 不是繪匣開的，畫面會提醒你重開一次 ComfyUI。

              MOSS 照參考圖的構圖畫：MOSS 模型＋「文生圖」打開「構圖控制」，放一張參考圖，勾「照深度」（姿勢、前後位置）和／或「照色塊」（每個東西放哪裡），MOSS 會照參考圖的構圖從頭畫，內容照提示詞。照片類參考圖「結束」用 1；3D 人偶這種合成圖用 0.5，比較不會畫成人偶。要用 ComfyUI 0.43 以後，第一次用會問要不要下載控制轉接器（約 300MB）。

              MOSS 天空出現直條紋：MOSS SFT 模型在天空、漸層、霧的地方容易有直條色帶。選 SFT 模型時勾「MOSS 去色帶」會自動掛修正（強度 1.0），沒有的話會問要不要下載（約 1.1GB）。

              MOSS 記憶體不夠：「MOSS 文字編碼器」切到 4B（省記憶體），用比較小的 Qwen3.5-4B 讀提示詞，改圖、構圖控制都能用；同一個種子畫出來會跟 9B 有點不一樣。第一次用會問要不要下載（約 4.8GB）。3070 8GB＋32GB 記憶體實測：記憶體最高點少約 1.4GB（13.4→12.0GB）、開站第一張快約 15 秒，顯存兩種都會用滿；省得不多，記憶體快不夠時再切。

                  生圖助手：用中文說，它自己畫到滿意

                    雲端會花錢：用 RunPod 時按「開雲端」會先顯示每小時價格，按「確定開機」才開始計費。不用時記得關掉。雲端只能畫 MOSS-Image。三種接法和申請步驟在下一章。

                    雲端顯卡：電腦不夠力，就接一張大卡

                    生圖助手選「雲端」腦袋時，35B 的腦袋和 MOSS-Image 生圖都改在雲端的大顯卡上跑：一輪十幾秒，眼力跟本機 35B 一樣，畫好的圖照樣存回你電腦的圖庫。8GB 的卡跑 35B 要好幾分鐘一輪，這時候接雲端最划算。

                    到「助手」頁右邊的「雲端顯卡」（或導演頁「H3 影片」分頁右邊）按 雲端設定…，三種接法選一種：

                    接法適合誰生圖站幫你做什麼
                    RunPod 自動租第一次用、想最省事租卡、安裝、閒置太久自動刪機，全包
                    任何雲端主機已經在用 Vast.ai、AutoDL、Lambda、TensorDock 這類，或有自己的伺服器用 SSH 連進你租好的機器自動安裝；開關機和計費在那家網站
                    直接連網址已經有在跑的 ComfyUI＋LLM（Colab、Kaggle、朋友的電腦…）只負責連過去用，什麼都不裝

                    接法一：RunPod 自動租

                    1. 到 runpod.io 註冊，左邊 Billing 先儲值一點錢（用多少扣多少）。
                    2. 左邊 Settings → API Keys → Create API Key，權限選 All（舊介面叫 Read/Write），建好後複製那串 rpa_ 開頭的金鑰（只顯示一次）。
                    3. 生圖站「助手」頁 → 雲端顯卡的 雲端設定… → 選 RunPod 自動租 → 貼上金鑰 → 儲存並測試連線，出現「RunPod 金鑰可以用」就好了。
                    4. 選一張卡（RTX A6000 每小時約 0.59 美元最划算），按 開雲端，看過價格按 確定開機。大約 3～5 分鐘燈號變綠，就能把腦袋切到「雲端」開始聊。
                    5. 用完按 關機刪除；忘了關也沒關係，閒置超過設定的分鐘數（預設 20）會自動刪機。

                    RunPod 關機＝刪機：下次開機會重新下載約 32GB 模型（機房網路很快，幾分鐘），這段時間也算錢。生圖站只會動自己開的那一台，你帳號裡的其他機器不會碰。

                    雲端要裝哪些功能

                    「雲端設定…」最上面可以勾這台雲端要裝什麼，勾越多開機下載越久：

                    功能用在哪下載量
                    生圖助手助手頁的「雲端」腦袋（35B）和 MOSS-Image 生圖約 32GB
                    H3 影片導演頁「H3 影片」分頁（第 14 章）約 42GB
                    H3 進階玩法H3 的換角色、特效、換畫風、動態桌布、動作控制再加約 32GB

                    48GB 的卡一次只能裝一個：生圖助手和 H3 一起勾要 96GB 的 RTX PRO 6000，選 A6000、L40S 時開機前會擋下來。機器開著時改了勾選，要關機再開才會裝。

                    接法二：任何一家雲端的主機（SSH）

                    先在那家網站租一台機器，條件：

                    項目需要
                    顯示卡NVIDIA 48GB 等級（RTX A6000、A40、L40S、RTX 6000 Ada、A100 80GB、H100…）
                    系統Linux（Ubuntu 22.04 以上），映像檔選有 CUDA 的（例如 PyTorch 映像檔）；驅動要支援 CUDA 12.8 以上
                    硬碟60GB 以上
                    連線能用 SSH 登入（大部分雲端都有）
                    1. 生圖站「雲端設定…」選 任何雲端主機 → 按一次 儲存，上面會出現生圖站專用的公鑰 → 按 複製公鑰。
                    2. 把公鑰加到那家雲端：Vast.ai 在帳號的 Keys → SSH Keys；Lambda 在 SSH keys；TensorDock、Paperspace 建機器時有欄位可以貼；AutoDL 這類用密碼登入的，先用網站上的終端機執行 mkdir -p ~/.ssh && echo "貼上公鑰" >> ~/.ssh/authorized_keys。（多數網站的帳號金鑰只套用到之後新開的機器：先加金鑰再開機最保險。）
                    3. 網站上會有一行 SSH 連線指令，像 ssh -p 41234 root@123.45.67.89。整行貼到「SSH 連線指令」那格，主機、埠、帳號會自動填好。
                    4. 按 儲存並測試連線：會顯示那台的顯卡、剩多少硬碟。連不上的話看下面的疑難排解。
                    5. 按 連線並安裝。第一次會在主機上下載 llama.cpp、ComfyUI 和約 32GB 模型，快慢看那家的網路；裝過的同一台再連只要一兩分鐘。
                    6. 用完按 停止：會停掉主機上的程式並斷線，裝好的檔案留著。主機本身要到那家網站關機或刪除才會停止計費。

                    想讓它閒置時自動關機：在「進階」勾「順便叫主機關機」。AutoDL 這類關機就停止計費；Vast.ai、Lambda 關機後可能還收硬碟費或照樣計費，要到網站刪除才算數。

                    接法三：直接連網址

                    • 你要先有：一個能從外面連的 ComfyUI 網址（最新版，裝好 MOSS-Image 三個檔），和一個 OpenAI 相容的 LLM 網址（llama-server、vLLM 都行，要看得懂圖，例如 Qwen3.6-35B-A3B 加 mmproj）。
                    • MOSS-Image 三個檔都在 Hugging Face 的 Comfy-Org/MOSS-Image：moss_image_sft_int8_convrot.safetensors 放 diffusion_models、qwen3.5_9b_w4a8_gptq.safetensors 放 text_encoders、flux2-vae.safetensors 放 vae。
                    • 「雲端設定…」選 直接連網址，填兩個網址（有 token、金鑰才填），按 儲存並測試連線，它會檢查 ComfyUI 有沒有那三個檔、LLM 有沒有回應。
                    • 按 連線 就能用。LoRA 不會自動上傳，要用的 LoRA 自己放進遠端的 models/loras。

                    金鑰都存在你這台電腦：RunPod 金鑰、網址模式的 token 用 Windows 的加密存起來，畫面上只會顯示「已存」，不會再秀出來。舊版用 Windows 環境變數 RUNPOD_API_KEY 的照樣認得。

                    漫畫台：一張圖畫出整頁分格漫畫

                    選一個版型，每一格寫景別、內容、台詞和狀聲詞，按「畫這一頁」，MOSS-Image 就把格子、人物和台詞一次畫成整頁漫畫，字直接畫在對話框裡。不用自己組提示詞，下面的「組好的提示詞」可以複製到生成頁自己改。漫畫台只用 MOSS-Image，要先把 MOSS 模型裝好。

                      • 格子照閱讀順序排，右上先。內容用英文寫最準；台詞寫中文，小格子的台詞放 8 個字以內最不會錯。

                      讓圖動起來，再接成一部短片

                      在觀景窗或大圖下面按「動起來」，寫一段「接下來發生什麼」：誰怎麼動、鏡頭怎麼移、聽得到什麼聲音。這張圖會變成一支有聲音的短影片（內建的 MiniMax H3），長度 3～10 秒。「在哪裡拍」選本機要先裝安裝精靈的「H3 影片（本機，選配）」包（見第 01 章「影片模型」），8GB 顯卡 512×768 5 秒約 3～4 分鐘；選雲端要先在「導演 → H3 影片」開好雲端（勾 H3 影片包），做好的影片一樣進圖庫。

                      • 動作和聲音用英文寫效果最好。不用再描述圖裡已經有的東西。台詞照要講的語言寫。
                      • 「快速（480p）」比「高畫質（720p）」快很多；本機裝了好幾顆 H3 模型時可以在「模型」下拉指定。
                      • 做影片前會先清空 ComfyUI 的記憶體，這段時間不能同時生圖。
                      • 想用別的影片模型？Wan、HunyuanVideo 這些也行：先在 ComfyUI 把影片工作流調到能跑，到「設定 → 影片模型」匯入：一般「儲存」的 JSON、「匯出（API）」的 JSON、ComfyUI 畫出來的 PNG／WebP 都可以（一般「儲存」的要開著 ComfyUI 才轉得了），匯入後會問要不要馬上改用。在正面提示詞的文字框寫 {{prompt}}，生圖站就知道你寫的東西要放哪裡；匯入後設定頁會列出它看懂了哪些地方（提示詞、首格圖、種子、長寬、長度）。

                      拍攝單：同一份分鏡，選不同影片引擎

                      在「影片」的拍攝單先選 H3 或已匯入的工作流，再填角色、首幀、場景、聲音與每段動作。每段秒數會個別保存。H3 沿用原本的短片／長片流程，自訂工作流會建立導演專案；這個選擇不會更改設定頁的預設影片模型。只有文生影片的自訂工作流可以不放首幀。以前選 LTX 的拍攝單，打開會自動換成 H3。

                      • 連戲狀態：展開每鏡的「開始狀態」「結束狀態」，自由填站位、姿態、哪隻手拿什麼、視線、服裝、光向與鏡頭軸線。開始狀態空白時可沿用上一鏡結束；手填內容優先，程式不會替你補造沒填的事實。
                      • 逐鏡審片：勾選後，拍好一鏡先停下讓你比較版本；在「拍攝版本」按「採用這版」後再繼續。取消勾選可連拍並自動採用新結果。
                      • 保留版本：重拍留下原片、首末幀與生成配方。切回另一版時，依賴它的後續鏡頭會失效，需要重拍或選回相容版本；歷史影片仍保留。切版前的未拍草稿可以另外套回。
                      • 選接續畫面：導演台（H3／自訂工作流）拍好並採用後，可從片尾候選影格選下一鏡要承接的畫面。選較早的影格時，合片會一起裁掉後面的片尾；保留原片。H3 長片使用自己的交棒點與 latent，不用靜態圖片替換接續資料。
                      • 命名素材槽：在「設定 → 影片模型 → 對應與參數」把工作流的圖片、影片、聲音欄位取名，指定首幀、角色、場景、動作或聲線用途。之後「動起來」及導演鏡頭會顯示對應素材欄位；沒有提供的槽沿用工作流原值，節點連線不能拿來當文字欄位覆寫。

                      導演台：一整段故事變成長片

                      • 在導演頁的「影片」分頁，把下面的執行區切到導演台那一區（原本的「分鏡」分頁就是這一區）。影片用內建的 MiniMax H3；「在哪裡拍」選本機或雲端（雲端要先開好、勾 H3 影片包）。
                      • 貼上整段故事或小說片段，按「AI 分段＋寫提示詞」，它會照劇情切成好幾個鏡頭，每段寫好提示詞。
                      • 在「管理角色…」建角色卡：放一張原圖、寫外觀描述，或按「做多視圖設定圖」。每段都會照這張卡畫，長相比較穩。
                      • 按「全部生成」：每段先畫第一格，再做成影片；接上一段的鏡頭直接拿上一段的最後一格。最後按「接成長片」。
                      • 本機 8GB 顯卡 5 秒一段約 3～4 分鐘（480p），720p 更久；雲端 L40S 10 秒一段約 4 分鐘。段數多的話整部片要跑很久，建議睡前或出門前開跑。

                      導演頁包含：影片、剪輯台、拆幀台三個分頁。原本獨立的「分鏡」已併進「影片」：影片分頁底下有三種執行區（H3 短片、H3 長片、導演台），拍攝單選的引擎和段數會自動帶你到對應的那一區，也可以自己手動切。舊版留在「分鏡」「H3 影片」「長片」的畫面，更新後會自動轉到對應的位置。

                      H3 影片台：素材板＋分鏡，一支片用滿 H3

                      「H3 影片」分頁用 MiniMax H3（預設 10Eros 無審核版）做 1～15 秒、有聲音的影片。左邊是素材板：圖、影片、聲音丟進來，每一格選「拿來幹嘛」；中間是分鏡卡：一鏡一張，寫從第幾秒、鏡頭、畫面、台詞、聲音；程式照這兩樣自動組成 H3 官方格式的提示詞。參考圖、首尾幀、關鍵幀、聲線、動作參考、接續、改造原片可以全部疊在同一支片上。H3 很吃顯存，一般都在雲端跑（8GB 卡可以用 GGUF 量化版慢慢跑）。

                      1. 右邊「在哪跑」選 雲端顯卡，按 雲端設定…，勾 H3 影片（用到換角色、特效、換畫風、動態桌布、骨架控制還要勾 H3 進階玩法），按儲存，再按 開雲端。
                      2. 點一個起手式（空白開始、用某人的聲音講新台詞、照影片的動作、首尾幀、接著上一支拍、換角色、加特效、骨架控制、照聲音對嘴、動態桌布）。它只是幫你先擺好素材格和長度，之後全部能改。舊的 39 個範本在「舊範本」下拉。
                      3. 素材板每一格按「圖庫」或「上傳」放素材，再選用途：圖可以當角色、服裝、場景、道具、分鏡板、畫風，或「釘在第幾秒」（首幀、尾幀、關鍵幀）；影片可以取動作、取運鏡、取角色、從它結尾接著拍、整段改造、骨架控制；聲音可以取音色、當背景音樂、當音效，或「原封不動放進去」讓畫面對嘴。角色可以取名字、指定誰是說話的人（S1、S2…）。
                      4. 在「點子」用中文寫想要的片，按 AI 幫我寫滿分鏡：它照素材的用途把每一鏡寫滿（已經寫的會留著）。分鏡卡每一格都能改：台詞照原文寫，不用翻。
                      5. 右邊選長度、畫質，按 開始做影片。做好的影片進圖庫、也出現在「成品」；成品下面的 接著拍 會開新的一支，從這支的結尾接下去。用完記得 關機刪除。
                      • 上限照 H3：參考圖 9 張、參考影片 3 段、參考聲音 3 段，合計 12 個；釘在時間點的圖 6 張。素材板上方即時算，超過或互相衝突（例如接續又在第 0 秒釘圖）會標紅、送出前擋下。
                      • <Picture 1>、<Video 1>、<Audio 1> 這些編號程式自己算，素材格左上角看得到；分鏡的畫面裡可以直接寫它們。
                      • 「完整提示詞」可以展開來看、直接手改；手改後分鏡卡不會再蓋掉它，按「照分鏡重組」才會重新組。
                      • 角色的聲音：角色格可以寫「聲音」（例：少女聲，偏低，性感知性），它會寫進提示詞，那個角色每句台詞都用這種聲音。只靠文字描述，每支片的聲音會有點差；要每支都同一把聲音，在聲音格按 聲音庫：把一段滿意的聲音「存進聲音庫」，以後每支片都從聲音庫挑同一段當「取音色」。
                      • 用 TTS 做聲音：聲音庫可以「匯入 TTS 工作流…」（ComfyUI 的文字轉語音工作流，要念的文字欄位寫 {{text}}、聲音描述欄位寫 {{voice}}），之後寫名字、聲音描述、一句台詞按「用 TTS 做一段」，做好的聲音存進聲音庫、放進這格。這個功能目前只做好接口，還沒用真的 TTS 節點測過。
                      • 畫質：快（16:9 約 864×480）、標準（約 1056×608）、高（約 1344×768）。「進階」的「高畫質二采」只能用在沒有釘圖、接續、改造原片的片；「SelfLift 兩段取樣」「加速」在 8GB 卡實測快很多。
                      • 「設定 → 影片模型」預設就是 MiniMax H3（內建）：生成頁和圖庫的「動起來」直接用 H3 做，不用先到 H3 分頁。
                      • 標「進階玩法」的社群 LoRA（換角色、特效、換畫風、動態桌布）還沒在雲端完整驗過，結果可能不穩。

                      長片：一段一段接著拍，接成一支

                      「長片」分頁把好幾段排成一條，按一次就在雲端一段一段拍下去：第 2 段起直接接著上一段的結尾拍（不是取最後一格重畫，畫質不會一段一段掉），每段拍完自動切掉重疊的開頭和定住的尾巴，最後在這台電腦接成一支放進圖庫。只能用雲端。

                      1. 先到「H3 影片」分頁開好雲端（要勾 H3 影片）。
                      2. 回到「長片」按 ＋ 新的。上面填整條共用的：角色參考圖、第 1 段的第一格（可不放）、角色外觀、場景與鏡頭、畫風、角色的聲音、環境音、比例、畫質。外觀和場景用英文寫最穩，每段的提示詞都從它們開始。
                      3. 中間一段一段寫：秒數（10 秒最穩）、這段發生什麼、台詞（第幾秒、什麼語言、說什麼）。尾幀可以不放，預設不放：釘了不同狀態的尾幀，模型會在半路瞬移。
                      4. 按 開拍整條（右邊會先算好大約要多久、多少錢）。拍好的段會出現預覽和檢查結果；按 停 可以中途停下，拍好的段都留著。
                      5. 全部拍好會自動接成一支進圖庫；按 看接好的長片 打開。
                      • 每段拍完會用拆幀台檢查硬剪接和跳點，有問題標紅（只標出來，不會自動重拍）；按 拆幀台看 一格一格看。
                      • 不滿意哪一段，按那段的 從這段重拍：後面的段是接著它拍的，會一起作廢重拍。
                      • 換場景、換姿勢寫成動作（轉身、起身、走過去、低頭擋住鏡頭），比硬接兩個不同的畫面自然。
                      • 第一次開拍時，生圖站會把接續用的社群節點（Herrgotts H3 Infinite，生圖站自己帶的固定版本）裝到雲端並重開雲端的 ComfyUI，多等一兩分鐘。
                      • L40S 實測：每 1 秒影片大約要算 25 秒；第一次載入模型另外要十幾分鐘。

                      剪輯台：把影片剪成一部片

                      • 第一次打開會請你按「下載剪輯工具」（Node.js 和 ffmpeg，約 150MB，只要下載一次，放在生圖站自己的資料夾）。用安裝精靈裝的話已經順便裝好了。
                      • 在觀景窗、大圖或圖庫按「送到剪輯台」，圖和影片就會出現在剪輯台左上的「專案」素材區，拖到下面的時間軸就能剪。
                      • 常用鍵：空白鍵 播放、S 切一刀、Del 刪掉、Shift＋Del 刪掉並把後面補上來、Alt＋T 加轉場。剪輯台是開源的 FableCut，介面語言跟著生圖站切換（設定頁最上面），右上「操作提示」有常用鍵整理。
                      • 字幕、圖形、字型、音效、字卡範本都在素材區上面的分頁。自己找的免費音效丟進音效資料夾（「操作提示」裡有按鈕打開）。
                      • 剪好按右上「⬇ 匯出」存成 MP4，回到生圖站按「匯出的影片…」→「存回圖庫」。「放大」可以讓剪輯台佔滿整個視窗，右下角的紅色按鈕縮回來。

                      拆幀台：一格一格修 AI 影片

                      GPU 解碼優先：預設要求 NVIDIA CUDA 解碼，失敗自動改 CPU，可取消勾選。PNG 壓縮及寫入仍使用 CPU，短片不一定更快。拆幀存在資料資料夾的 data\frames\每次拆幀編號，包含圖片、縮圖、聲音和修幀紀錄。按「空間與清理…」可查看位置與占用，永久清除目前這份，或清空先前移到「待刪除\拆幀台」的拆幀。會先確認，原影片及接回後的影片保留；修幀成果會一起刪掉，請先接回影片。

                      • 大圖或圖庫裡的影片按「拆幀修片」，或在拆幀台按「拆一支影片…」。10 秒 24fps 的影片會拆成 240 張。
                      • 不是生圖站做的影片也能拆：按「從電腦選影片…」挑任何影片檔（原檔不會動）。
                      • 長片先看硬碟空間（拆完至少留 5GB）：旁邊填「從／到（秒）」只拆一段；填「每秒幾幀」先抽樣粗看整支；填「最高（像素）」把大圖縮小，省硬碟。
                      • 點右邊的格子，或按 ← → 一格一格看，空白鍵 播放，最容易找到閃一下的壞幀。
                      • 閃一下、糊掉的單一幀：按「前後平均補幀」；也可以用前一幀或後一幀蓋掉。
                      • 整張壞掉：按「拿去局部重繪」塗掉重畫，畫好回到拆幀台，按黃框裡的「選畫好的圖換進去」。
                      • 按「接回影片」：用原本的聲音和幀率接成一支新影片存進圖庫，原本那支不動。改過的幀標號是橘色，「換回原本的」可以還原。

                      讓 AI 幫你操作

                      • 按導演頁右上（或設定頁）的「給 AI 操作…」，把 MCP 設定複製到 Claude Desktop、Claude Code 或 Codex CLI，AI 就能操作整個生圖站：生圖、看圖庫、漫畫台、導演台、H3 影片，也能剪接、配樂、加字幕、匯出，你在剪輯台看得到它即時在改。
                      • 會花錢、刪東西、改設定的事，AI 一定會先問你，你說好才會做。以前貼過 fablecut 設定的，換成新的 anima 那一段。
                      • 接不了 MCP 的 AI，按「複製說明」貼給它，它就知道全站每個功能的網址和用法。
                      • ChatGPT 網頁版和手機 App 連不到你電腦裡的程式，用不了。

                      任務面板：一次排很多張

                      生成鍵可以連按，每次送出的都會排隊。按 Q 打開任務面板，看哪張在畫、還要等多久、哪張失敗了。

                        • 面板上面勾「提示音」，畫好會響鐘聲，失敗是兩下悶響。
                        • 勾「完成時通知我」，視窗縮小時畫好會跳 Windows 通知。
                        • 「全停」會清空佇列並停掉目前這張；「清掉已結束的」只清紀錄，不會刪圖。

                        設定：改壞了也救得回來

                        設定頁由上到下：介面語言（繁體中文／简体中文／English，換了會重新整理一次；教學手冊維持繁中）、Civitai API key、網路（代理、下載來源）、ComfyUI 啟動方式、成人預覽模糊、AI 改寫的執行方式、自訂改寫規則、影片模型、模型與工作流、等圖時的小玩具、關閉視窗時要做什麼、預設負面提示詞、匯出匯入設定、恢復原廠，最後是資料位置和「安裝與修復」。

                          • 網路（代理、下載來源）：在中國大陸下載模型要開梯子。預設「自動」：跟著系統代理、PAC、環境變數走；梯子開 TUN（虛擬網卡）模式也能通；梯子關了但系統代理忘了關，會自動改直連。讀不到的話選「手動」填代理（例如 http://127.0.0.1:7897 或 socks5://127.0.0.1:7898）。Hugging Face 下載來源預設「自動」：連不上就改用鏡像 hf-mirror.com。按「測試連線」會逐一測 Hugging Face、鏡像、GitHub、Civitai、Node.js，連不到的會寫原因和怎麼辦。
                          • ComfyUI 啟動方式：最上面會寫目前這份 ComfyUI 是哪一種（NVIDIA、AMD、Intel、ZLUDA、DirectML、CPU 版）。「ComfyUI 額外啟動參數」會接在生圖站自己的參數後面，例如顯存小可以填 --lowvram；--port、--output-directory 這些由生圖站管，不能放。勾「我自己開 ComfyUI」的話，生圖站不會自己開，你用平常的方式開在同一個連接埠，它會自己連上。「Python 位置」給 Python 放在別處的 ComfyUI（conda、外面的 venv），空白＝自動找。「ComfyUI 的連接埠」空白＝自動：用 8188，被另一份 ComfyUI 占走時生圖站自己這份會換一個空的；自己開在別的連接埠（SwarmUI、改過的整合包）就填它。最上面也會寫這份 ComfyUI 的版本，比生圖站測過的舊會提醒。「用 CPU 跑」是給沒有能用的顯示卡的電腦。改完按「儲存並重開 ComfyUI」才生效。
                          • AI 改寫執行方式：GPU 最快（約 6～8 秒，占 5.5GB 顯存），CPU 不占顯存但很慢。成人（體位）和導演台用的通用模型，選「自動」時有 35B 就用 35B；AI 改寫面板的「用哪顆模型」也能直接切。
                          • 自訂改寫規則：可以改改寫模型的系統提示詞。寫壞了按「還原預設」就回來。
                          • 模型與工作流：
                            • 外部模型資料夾：電腦裡別的地方已經有模型（別的 ComfyUI、A1111／Forge），把資料夾路徑貼進來就能原地使用，不搬也不複製。選「自動判斷分類」時，整個 ComfyUI 或 A1111 資料夾會自動拆成 LoRA、VAE、Checkpoint…各一筆。不知道放在哪？按「掃描這台電腦已有的模型」，勾選要用的。改完要重開 ComfyUI 才讀得到（會出現「重開 ComfyUI」按鈕）。移除只是不再讀，資料夾和檔案都不會被刪。
                            • 加裝模型：把模型檔拖進框裡（或按「選檔案」），生圖站看權重自動判斷是 LoRA、VAE、主模型還是其他，放進 ComfyUI 對的資料夾；看不出來的會請你選分類。也可以貼 Hugging Face、Civitai 的網址直接下載（Civitai 要登入的會用設定頁的 API key），或填電腦裡某個檔的路徑複製一份進來。
                            • 生圖工作流：自己的 ComfyUI 工作流（SDXL、Pony、Illustrious、Flux、SD1.5 都行）匯進來，就能在生成頁用。詳細見本章最後「用自己的 ComfyUI 工作流」。
                            • 取代內建功能：例如想讓 Anima 的局部重繪改用你自己調的流程：先在生成頁按「拿去 ComfyUI 改…」把內建的存下來，在 ComfyUI 改好，用「匯入工作流…」匯進來（模式選「自動判斷」就會認出是局部重繪），匯入完按「取代」；也可以到這裡把 Anima 那一列「局部重繪」的選單從「內建」換成那一組。之後照常選 Anima、按局部重繪，跑的就是你的版本；選回「內建」就恢復。
                            • 模型總覽：展開就列出生圖站看得到的所有模型（哪些在外部資料夾），還有安裝精靈清單裡還缺哪些。
                          • 軟糖小熊：等圖時掉進觀景窗的小熊，可以用滑鼠抓起來甩。嫌吵可以在這裡關掉。
                          • 匯出設定檔：設定、提示詞庫、LoRA 觸發詞與備註、生圖工作流組、影片工作流、改過的 AI 改寫規則，全部存成一個檔，換電腦或重灌後匯入就還原。不含 Civitai API key、代理設定和模型資料夾位置；工作流裡像金鑰的欄位會清空。匯入時同名但內容不同的舊檔，會先搬進資料夾裡的「待刪除\匯入前_日期時間」，不會直接蓋掉。
                          • 清理快取：先按「查看快取大小」，再按「清理全部快取」。會清除可重建的圖庫縮圖、AI 改寫快取、安裝下載與解壓暫存、安裝後壓縮檔和剪輯台預覽。原圖、影片、完整模型、專案、設定、金鑰和恢復原廠備份保留。生成、安裝或下載還在跑時不能清，剪輯台也要先關閉。未完成的安裝下載清掉後要重新下載；無法存取的檔案會略過並回報。
                          • 診斷紀錄與錯誤回報：操作失敗時可按提示上的「下載診斷包」，也能在任務面板按「診斷包」，或到本頁查看紀錄。會保存提示詞、實際參數、API 工作流、模型載入、節點錯誤與本機程序輸出取樣；結果沒照指令時，按「結果不符」填寫原本想要與實際遇到的情況，再下載 ZIP 給查修的人或 AI。包內先讀 report.txt、manifest.json 與 critical.jsonl。重開後未正常結束的操作會標為「結果未確認」，不會直接認定是崩潰。預設成功保留 1 天、異常與手動回報 3 天、總額 500 MiB、單次 100 MiB，可在這裡調整與清理。只自動刪除自己的舊診斷；圖片、影片、模型不會被收進去或清掉。執行中、待確認與下載中的紀錄會保護，額度不足時會標示診斷不完整。已知金鑰與網址在保存前遮蔽，不會自動上傳；文字提示詞仍可能含私人資料，分享前請檢查。原有的 ComfyUI／llama-server 原始 log，以及瀏覽器下載出去的 ZIP，需另外管理。

                          用自己的 ComfyUI 工作流

                          到「設定 → 模型與工作流 → 生圖工作流」匯入。ComfyUI 存的工作流（.json）、「匯出（API）」的 JSON、ComfyUI 畫出來的 PNG／WebP（圖裡帶著工作流）都可以。一組工作流可以有好幾種模式：先匯入文生圖，再匯入一次、「放進哪一組」選「加進『那一組』」，補圖生圖、局部重繪、放大、多圖參考。生成頁的模型選單最下面會出現「⚙ 工作流組名字」，選它時只有這組有的模式能按。

                          • 生圖站自己會找：正面、負面提示詞、種子、寬高（文生圖）、Load Image、Save Image 大多自動認得。認錯或認不到時，在節點的標題或文字框裡寫標記告訴它：
                          • {{prompt}}、{{negative}}：正面、負面提示詞放這裡。{{image}}：輸入圖（圖生圖、局部重繪、放大）。{{mask}}：遮罩（局部重繪；也可以用同一張 Load Image 的遮罩輸出）。{{ref1}}、{{ref2}}…：多圖參考的第幾張。{{model}}：主模型的載入節點（LoRA 接在它後面）。{{sampler}}：要吃生成頁步數、CFG、取樣器的取樣節點。
                          • LoRA：生成頁掛的 LoRA 會自動接在主模型載入節點後面，只接同家族的（例如 SDXL 的工作流只接 SDXL 的 LoRA；看不出家族的都接）。
                          • 工作流參數：生成頁會多一格「工作流參數」，列出這個工作流的步數、CFG、取樣器、模型檔…可以直接改，改的值會記住；按「還原工作流原本的值」就回來。紅字是這台電腦沒有的檔案或節點。勾「用生成頁的步數、CFG、取樣器」就改用生成頁那幾個旋鈕。
                          • 模式選「自動判斷」：生圖站匯出的檔自己認得；其他的檔看節點猜，例如 Load Image 接到 VAE Encode 當圖生圖、有 Set Latent Noise Mask 這類節點當局部重繪，猜不出來當文生圖。猜的結果會寫在匯入結果裡，不對就移除那個模式、選對再匯入一次。
                          • 找不到提示詞、輸入圖這些地方：匯入失敗的訊息底下會列出工作流裡的節點，直接選「哪一格是正面提示詞」「哪一個 Load Image 放輸入圖」，按「照這樣匯入」就好，不用回 ComfyUI 改標記。
                          • 缺節點：工作流用到你的 ComfyUI 沒裝的自訂節點、而且接在出圖的路上時，會告訴你缺哪幾個。用 ComfyUI Manager 裝好、重開 ComfyUI 再匯入。旁邊沒接到存圖或預覽的缺節點會自動拿掉，只提醒一聲。
                          • 模型檔名對不上：別人的工作流寫 SDXL/xxx.safetensors、你的是 SDXL\xxx.safetensors，或你把模型放在子資料夾裡，生圖站會自動換成你那一個；真的沒有的檔，到「工作流參數」把標紅的欄位換掉。
                          • 匯出：每一組都可以按「匯出」存成檔分享給別人，對方直接匯入就能用（標記都在裡面）。

                          疑難排解

                          狀況先試這個
                          狀態列 ComfyUI 的燈是紅的ComfyUI 沒開或當掉了。點狀態列的「顯存」那一格，如果 ComfyUI 是開到一半當掉，這裡會寫原因（少了某個 Python 套件、顯示卡驅動太舊、連接埠被占用、記憶體不夠…）和怎麼辦。照著處理後，把生圖站整個關掉（選「結束程式」）再打開，它會自己把 ComfyUI 帶起來。
                          下載模型一直失敗、說連不到 huggingface.co在中國大陸要開梯子。到「設定 → 網路」按「測試連線」看哪幾個網站連不到、原因是什麼；梯子讀不到就選「手動」填代理位址。Hugging Face 連不上時會自動改從鏡像 hf-mirror.com 下載。
                          A 卡、Intel 顯示卡：ComfyUI 一開就關掉這兩種都是實驗性支援。看狀態列「顯存」那格寫的原因：說「AMD 顯示卡用不起來」的話，先到 AMD 官網把 Adrenalin 驅動更新到最新；錯誤訊息有 invalid device function 的話，到「設定 → 安裝與修復…」第二頁看「A 卡架構」選得對不對，選好再按一次安裝。說「Intel 顯示卡用不起來」的話，更新 Intel Arc 驅動。說「這份 ComfyUI 的 PyTorch 是 NVIDIA 版」的話，到「安裝與修復」第二頁把「ComfyUI 版本」選成 AMD 或 Intel，換一個新位置重新下載。ZLUDA 版開不起來，多半是 HIP SDK 跟 ZLUDA 版本對不上，或 nccl.dll 被防毒刪掉。都不行的話可以改用「雲端顯卡」。
                          安裝時說「連不到 AMD 的套件庫」A 卡換 PyTorch 那一步要從 stable.repo.amd.com 下載約 1.1GB。檢查網路和梯子（「設定 → 網路」可以測試連線），再按一次「開始安裝」，已經下載完的檔不會重抓。換不成功的話，ComfyUI 照樣能開，只是用不到這張卡。
                          N 卡的 ComfyUI 一開就關掉，說這張卡比較舊（GTX 10 系列以前）新版 PyTorch 不支援 GTX 10 系列以前的卡。到「設定 → 安裝與修復…」第二頁把「ComfyUI 版本」選成「NVIDIA 舊卡」，換一個新位置重新安裝，會下載官方給舊卡的版本。
                          H3 影片說「雲端這台沒裝 H3 影片包」雲端開機時沒勾 H3。按「關機刪除」，到「雲端設定…」勾「H3 影片」（進階玩法再勾「H3 進階玩法」），再開一次。
