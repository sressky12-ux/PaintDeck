  • 首格圖：只有一個 Load Image 就用它；有好幾個時，把要放首格圖的那個節點標題改成 {{image}}。沒有 Load Image 的工作流只能文生影片，不能用在「動起來」和導演台。

  • 種子：所有 seed、noise_seed 欄位。
    •

    • 
          
  • 長度：讀得到每秒幾格（Create Video 的 fps、Video Combine 的 frame_rate）才照你選的秒數改，不然照工作流。
    • 
          
  • 存檔：Save Video、Save WEBM、Video Combine（VHS）存的影片收進圖庫；另外存第一格當縮圖、最後一格給導演台接下一段。

  • 其他（模型、步數、CFG、負面提示詞、LoRA）都照工作流。

生圖工作流

      
把你在 ComfyUI 調好的工作流匯進來：一般「儲存」的工作流 JSON、「匯出（API）」（Export (API)）的 JSON、ComfyUI 生成的 PNG／WebP 圖（圖裡帶著工作流）都可以，不用懂什麼是 API 格式。一個名字（一組）底下可以放好幾個模式：文生圖、圖生圖、局部重繪、放大、多圖參考。匯入後到生成頁的模型選單最下面「⚙ 生圖工作流」選它，模式鍵只會亮它有的模式，左欄會長出「工作流參數」。

      

      

        
        
        
        

      
「模式」是這個檔要當哪個功能用。選「自動判斷」時：生成頁「拿去 ComfyUI 改…」存的檔自己認得出是哪個功能，其他的檔看節點猜（例如 Load Image 接到 VAE Encode 當圖生圖），猜不出來當文生圖。找不到提示詞、輸入圖這些地方時，會列出工作流裡的節點讓你直接指定。生圖站自己匯出的工作流組檔（整組）不用選，會整組收進來。一般「儲存」的工作流（包括圖裡只帶一般工作流的 PNG／WebP）要靠你的 ComfyUI 轉換，匯入時 ComfyUI 要開著；缺哪些自訂節點會列出來。

      

      
生圖站會改工作流的哪些地方（標記）
        
    
          
  • 能匯入的檔：ComfyUI「匯出（API）」的 JSON、一般「儲存」的工作流 JSON（有 nodes、links 的那種）、ComfyUI 生成的 PNG／WebP 圖、生圖站自己匯出的工作流組檔。一般工作流裡被停用或略過（Mute、Bypass）的節點、Reroute、Note、Primitive 節點會自動處理。
    • 
          
  • 以下的位置，優先看你寫的標記（寫在節點標題或文字欄位裡），沒標記才自動找；其他地方一律照工作流原樣。
    • 
          
  • 提示詞：正面文字框裡寫 {{prompt}}，換成你寫的內容，前後的字保留。沒標的話，從取樣器的正面輸入往回找，只找到一個文字框就整格換掉。
    • 
          
  • 負面提示詞：負面文字框裡寫 {{negative}}，換成生成頁的負面提示詞；沒標的話從取樣器的負面輸入往回找。生成頁的負面提示詞空白時照工作流。
    • 
          
  • 輸入圖（圖生圖、放大、局部重繪）：Load Image 節點的標題寫 {{image}}；整個工作流只有一個 Load Image 時，不用標。
    • 
          
  • 遮罩（局部重繪）：Load Image（或 Load Image (as Mask)）的標題寫 {{mask}}。除了輸入圖之外還有第二個 Load Image 時，生圖站不猜，一定要標。
    • 
          
  • 參考圖（多圖參考）：Load Image 節點的標題寫 {{ref1}}、{{ref2}}……，生圖站不猜。
    • 
          
  • 主模型：載入模型節點的標題寫 {{model}}；沒標的話，用接到取樣器 model 輸入、最上游的那個載入節點（Load Checkpoint、Load Diffusion Model、GGUF 載入…）。放在工作流組裡時用工作流原本的模型（要換就在「工作流參數」選）；用在下面的「取代內建功能」時，換成生成頁選的模型。
    • 
          
  • 取樣參數：取樣節點的標題寫 {{sampler}}，只有標的會跟生成頁；勾了「用生成頁的步數、CFG、取樣器」時，所有取樣節點（KSampler、KSampler Advanced）的步數、CFG、取樣器、排程都用生成頁的。圖生圖、局部重繪的重繪幅度一律用生成頁的。
    • 
          
  • 種子：所有數字的 seed、noise_seed 欄位，每張加一。有好幾個取樣器（高解析修復、refiner）時全部都改。
    • 
          
  • 寬高：同時有 width、height、batch_size 的節點（Empty Latent Image 這類）。文生圖照生成頁的寬高，一次一張，張數照生成頁；其他模式的尺寸跟著輸入圖或工作流。
    • 
          
  • 存檔：Save Image 的檔名前綴會改成 AnimaWeb/模式，圖庫才收得到。
    • 
          
  • LoRA：生成頁選的 LoRA 自動接在主模型載入節點的後面（一個接一個）；工作流裡原本的 LoRA 節點保留，強度在「工作流參數」調。LoRA 照模型家族篩，家族不合的會略過並提示。
    • 
          
  • 工作流參數：選了工作流組後，生成頁左欄會照工作流每個節點的欄位長出面板（型別、範圍、下拉選項讀自你的 ComfyUI）：常用的在上面，其他收在「進階」。改過的值最後才套上，比上面這些自動規則優先；「還原工作流原本的值」清掉全部。工作流裡的檔案（模型、LoRA）這台電腦沒有時，欄位會標紅，請選一個再生成。
    • 
        

      


      
取代內建功能

      
想改生圖站內建的功能（例如 Anima 的局部重繪、放大）：到生成頁選好模式和設定，按模型旁邊的「拿去 ComfyUI 改…」存成檔，用 ComfyUI 打開改好（標記不要刪），再用上面的「匯入工作流…」匯進來，匯入完按「取代」，或在這裡指定。之後用那個家族的模型做那個模式，就跑你改過的版本；主模型用生成頁選的那個。選回「內建」隨時切回來。

    讓 AI 操作生圖站
    
    
    支援 MCP 的 AI 程式（Claude Desktop、Claude Code、Codex CLI、Cursor…）可以直接操作整個生圖站：生圖、看圖庫、漫畫台、導演台、H3 影片、生圖助手、提示詞庫、資產庫，也能剪片（你在「剪輯台」分頁看得到它即時改）和修幀。會花錢、刪東西、改設定的操作，AI 一定要先問過你才會做。
    生圖站要開著 AI 才連得到。ChatGPT 網頁版、手機 App 連不到你電腦裡的程式，用不了。
    
    
    
    Claude Desktop：設定 → 開發者 → 編輯設定，把下面 anima 那一段放進 mcpServers（以前貼過 fablecut 的，換成這一段），存檔後重開 Claude。Claude Code：存成專案資料夾裡的 .mcp.json，或跑 claude mcp add。Codex CLI：按「複製 Codex 版」貼進 ~/.codex/config.toml。Cursor：貼進 %USERPROFILE%\.cursor\mcp.json。
    
    
    
    
    
    
    接了 MCP 的 AI 會自己讀說明，這步可以跳過。沒辦法接 MCP 的 AI，把這段貼給它：裡面有主要功能的網址和用法；沒一條一條列到的用 anima_api 直接打，權限一樣（會花錢、刪東西、改設定的還是要先問你）。
    
    
    
    
    
    
    接好之後直接開一個新對話，把這段貼給它，它就知道要先看狀態、讀說明、動手前先問你。

    雲端顯卡設定
    
    
    電腦不夠力時，把生圖助手的腦袋（35B）和生圖（MOSS-Image）放到雲端的大顯卡上跑，畫好的圖一樣存回這台電腦的圖庫。三種連法選一種：
    
    
    
    
    
      雲端要裝哪些功能（勾越多，開機下載越久、硬碟越大）
      
      
      
      
    生圖助手和 H3 一起勾要 96GB 的卡（RTX PRO 6000）；48GB 的卡（A6000、L40S）一次只能用一個。機器開著時改了，要關機再開才會裝。
    
    
    

    
    
      
    生圖站幫你租卡、安裝、用完刪機，最省事。按「開雲端」前會先顯示每小時價格（RTX A6000 約 0.59 美元），閒置太久會自動刪機。
    
      
      
    
      
    申請：runpod.io 註冊並儲值 → 左邊選單 Settings → API Keys → Create API Key（權限選 All）→ 複製貼上。金鑰加密存在這台電腦，不會送到別的地方；舊版用的 Windows 環境變數 RUNPOD_API_KEY 也還認得。
    
    
    

    
    
      
    在任何一家雲端（Vast.ai、AutoDL、Lambda、TensorDock、Paperspace…或自己的伺服器）先租好一台 Linux 機器，條件：NVIDIA 48GB 等級的卡（A6000、A40、L40S、A100 80GB…）、驅動支援 CUDA 12.8 以上、硬碟 60GB 以上、能用 SSH 登入。生圖站會連進去自動安裝，開關機和計費在那家的網站。
