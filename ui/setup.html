歡迎！先看看這台電腦

繪匣 PaintDeck 在你自己的電腦上用 AI 畫圖，畫圖的引擎是 ComfyUI。接下來幾步會決定資料放哪裡、裝好需要的東西。每一步都可以重來，已經有的不會重複下載。

正在檢查這台電腦…
網路
模型從 Hugging Face、GitHub、Civitai 下載。在中國大陸要開梯子（系統代理、PAC、TUN 模式都可以）；Hugging Face 連不上會自動改用鏡像 hf-mirror.com。下面會先測一次連線。

資料和 ComfyUI 要放哪裡？

「資料」是圖庫紀錄、設定、預設組、反推模型；生成的圖本身存在 ComfyUI 的 output 資料夾。電腦裡找到舊版生圖站的話，直接沿用就能看到以前的圖。

要下載哪些生圖模型？

模型從官方來源（Hugging Face、GitHub、Civitai）下載到 ComfyUI 的 models 資料夾。已經有的會跳過，網路斷掉之後再按一次會接著下載。

按「開始安裝」時會先加密儲存，再用來下載模型。留空會沿用既有金鑰。
到 Civitai 帳號設定取得 API 金鑰
這台電腦已經有模型了？
別的 ComfyUI、A1111／Forge 裡已經有的模型可以原地使用，不用再下載一份，也不會搬動檔案。進到這頁會自動掃描每顆硬碟，大概要一兩分鐘。
要裝哪些功能？打勾自選，或用下面的快速鈕選
全不選的話，只裝 ComfyUI、節點、反推模型，之後隨時可以回來這頁補勾。常用 LoRA 裡有些需要 Civitai 金鑰；可以在上方先填，也可以之後到「設定」填好，再回來補下載。
